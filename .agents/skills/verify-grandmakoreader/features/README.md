# GrandmaKOReader verification map

Use the [launch, doctor, and evidence workflow](../SKILL.md) to prepare the runtime and allocate `$evidence`. Each recipe uses the full review with two disposable books. The screenshots and logs are grouped by orientation.

- [Books and reading position](books.md) covers launch, the three places, shelves by letter, Look up a book, book selection, USB refresh, and resuming a book.
- [Page input and font preview](reading.md) covers the tap menu, swipe and button paging, and saving a font change.
- [Frontlight and sleep](device-controls.md) covers frontlight steps, dismissal, and the sleep preview.
- [Low battery](battery.md) covers the warning threshold and recovery.
- [End of book](end-of-book.md) covers Andrew's note, the four choices, confirmation, and persisted effects.
- [Wi‑Fi](wifi.md) covers connecting while something needs it, disconnecting when idle, failures, and sleep.
- [Automatic updates](auto-update.md) covers checking, the Check for updates button in Settings, downloading, restarting, and rolling back. It has its own run, `tools/review-auto-update`.
